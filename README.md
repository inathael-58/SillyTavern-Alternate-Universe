# Alternate Universe — SillyTavern extension

**แตก branch ใหม่จากแชท แล้วล้างแท็กและ CoT ของ preset ที่ใช้อยู่ออก** เปลี่ยน preset กลางเรื่องได้โดยไม่มีของเก่าของ preset เดิมติดมา แชทต้นฉบับไม่ถูกแตะ

## ปัญหาที่แก้

แต่ละ preset สั่งให้ model เขียนแท็กของตัวเอง เช่น `<status>`, `<summary>`, HTML panel หรือ `<think>` และมี regex ของตัวเองไว้ซ่อนแท็กพวกนั้นตอนแสดงผลหรือตอนส่ง prompt แต่ข้อความที่บันทึกในแชทยังเก็บแท็กไว้ครบ พอเปลี่ยน preset regex ชุดเดิมก็ไม่ทำงานแล้ว แท็กเก่าจะโผล่บนจอ หลุดเข้า prompt และ model ตัวใหม่ก็จะเขียนตามรูปแบบเก่า

## ติดตั้ง

Extensions → Install extension → วาง URL ของ repo นี้

## ใช้งาน

**ก่อน**เปลี่ยน preset ให้กดเมนู ☰ ซ้ายล่าง → **Alternate Universe** (หรือพิมพ์ `/alternate-universe` หรือ `/au`)

1. **Regex ที่ใช้ตอนส่ง prompt** แสดงรายการ regex แบบ *Alter Outgoing Prompt* ที่เปิดอยู่ตอนนี้ (Global · Preset · การ์ดตัวละคร) ข้อความใน branch จะถูกเขียนทับด้วยผลของ regex พวกนี้ ได้ข้อความแบบเดียวกับที่ preset ปัจจุบันส่งให้ model จริง ๆ ไม่ต้องไล่ทำรายการแท็กเอง
   - **ใช้กับทุกข้อความ ไม่สนช่วง depth** (เปิดไว้เป็นค่าเริ่มต้น) regex ที่ตั้ง Min/Max Depth ไว้ เช่น "เก็บ status ไว้แค่ข้อความล่าสุด" จะถูกใช้กับทุกข้อความด้วย ถ้าปิด จะใช้ตามช่วง depth เหมือนตอนส่ง prompt ครั้งล่าสุด
2. **CoT / reasoning** ลบทั้ง reasoning ที่ parse แยกไว้แล้ว (กล่อง "Thought for…") และบล็อก `<think>` / `<thinking>` หรือคู่ prefix/suffix ของ Reasoning Formatting ที่ค้างอยู่ในเนื้อข้อความ
3. **แท็กเพิ่มเติม** ใช้กับแท็กที่ regex ของ preset ไม่ได้จัดการ
   - *ลบทั้งก้อน* ลบตั้งแต่ `<status>` ถึง `</status>`
   - *ลบแค่แท็ก* ลบแค่ `<scene>` กับ `</scene>` แต่เก็บข้อความข้างในไว้
   - ลบ HTML comment `<!-- -->` และเก็บบรรทัดว่างที่เหลือจากการลบ
   - **จำรายชื่อแท็กไว้กับ preset นี้** บันทึกลงไฟล์ preset (`extensions.alternateUniverse`) เปิดครั้งหน้าบน preset เดียวกันจะเติมให้เอง และติดไปด้วยตอน export preset
4. **ขอบเขต** เลือกได้ว่าจะแตกจากข้อความที่เท่าไหร่ (ค่าเริ่มต้นคือข้อความล่าสุด) จะล้างข้อความของผู้ใช้ด้วยไหม และจะล้างทุก swipe หรือเก็บไว้แค่ swipe ที่เลือกอยู่
5. **หลังล้างเสร็จ** เลือก preset ที่จะเปลี่ยนไปใช้ได้เลย

กล่อง **ตัวอย่าง** ด้านล่างแสดงข้อความ AI ล่าสุดหลังล้าง และนับให้ว่าจะเปลี่ยนกี่ข้อความ อัปเดตทันทีที่แก้ค่า

กด **แตก branch และล้าง** แล้ว SillyTavern จะสร้าง branch แบบเดียวกับปุ่ม Branch ปกติ (`ชื่อแชท - Branch #n`) เปิดให้ ล้างข้อความใน branch นั้น บันทึก แล้วค่อยเปลี่ยน preset ถ้าเลือกไว้ แชทเดิมยังอยู่ครบ กลับไปได้ที่ Manage chat files หรือ Back to parent chat

## หมายเหตุ

- ต้องกด **ก่อน**เปลี่ยน preset เพราะ extension ใช้ regex ที่เปิดอยู่ตอนนั้น ถ้าเปลี่ยนไปแล้ว ให้สลับกลับไป preset เดิมก่อนค่อยกด
- ถ้าใช้ [Preset Formatting](https://github.com/inathael-58/SillyTavern-PresetFormatting) ตอนเปลี่ยน preset ในขั้นที่ 5 Regex Preset ของ preset ใหม่จะถูกตั้งให้อัตโนมัติเหมือนเปลี่ยนเอง
- regex แบบ *Alter Chat Display* (แสดงผลอย่างเดียว) จะไม่ถูกใช้ เพราะมักแปลงแท็กเป็น HTML สำหรับแสดงผล ไม่ได้มีไว้ส่ง model
- ถ้าข้อความเคยผ่านหลาย preset ปนกัน regex ในขั้นที่ 1 จะล้างได้แค่ส่วนที่ preset ปัจจุบันรู้จัก ส่วนที่เหลือใส่ไว้ในขั้นที่ 3
- ถ้าใช้ extension ที่สรุปความจำ (เช่น Memory Hub) แล้วสรุปอ้างถึงแท็กเก่า อาจต้องสร้างสรุปใหม่ใน branch
- branch ที่สร้างจะมี `chat_metadata.alternateUniverse` บอกว่าแตกมาจากแชทไหน ข้อความที่เท่าไหร่ และ preset อะไร
